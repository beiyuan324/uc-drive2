## 新增

- 接入夸克、百度、迅雷官方分享链接解析，支持提取码、目录浏览、单文件与递归批量下载。
- 三家网盘下载统一由 Gopeed 执行，完成后登记到本地文件树，历史记录支持重新取链下载。
- 设置页增加各平台独立的加密凭据保存与清除入口。

## 修复

- 百度改用官方分享列表返回会话，修正签名参数、提取码会话编码、短分页和大整数文件 ID 处理。
- 限制本地 API 的网页来源与 Host，阻止外部网页跨域调用及 DNS 重绑定访问。
- 迅雷转存等待官方任务完成并核对文件映射，拒绝返回其他文件的下载结果。

## 使用说明

- 本版只调用网盘官方接口，不接入第三方解析服务；账号权益、验证码及下载限制遵循官方规则。
- 迅雷需从官网提供登录与校验请求头，校验令牌过期后手动更新。普通分享无直链时会转存所选文件到本人云盘根目录，转存文件保留。
- 自动化验证使用本地 HTTPS 官方接口契约夹具及真实 Gopeed，覆盖完整文件下载、暂停继续、文件登记和历史重新下载；未使用真实网盘账号进行联网验收。
